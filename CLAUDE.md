# CaseLightning / CONVEYi

Before changing the engine, the Tasks list, issues, decisions, triggers, waits, rules or a firm's configuration, read `docs/spec/README.md` and the file for the area. A change is done when it keeps those rules and `npm run test:unit` passes, including the stall detector (`tests/unit/engine/no-stall.test.ts`). Check UI changes on `/dev/harness` (local only) at 1280–1400px before shipping.
